BAC Iunie 2016

Subiectul III - 1: Afișarea cifrelor unui număr

Se analizează ieșirea unei funcții recursive care afișează cifrele unui număr dat.

📜 Enunțul problemei

Enunț: Subprogramul f este definit alăturat. Indicați ce se afișează în urma apelului de mai jos.

Apel: f(2016);

void f(int n) {
    if (n != 0) {
        cout << n;
        f(n/10);
    }
}

Exemplu: a. 6102   b. 2202012016   c. 2016201202   d. 20162012020
