Operatori în C++

Tipurile de operatori, evaluarea expresiilor și capcanele frecvente din programa de BAC

Ce este un operator?

Un operator este un simbol care indică o operație ce trebuie efectuată asupra unuia sau mai multor operanzi. În funcție de numărul operanzilor, operatorii pot fi unari (un operand), binari (doi operanzi) sau ternari (trei operanzi).

Operatori aritmetici

Se folosesc pentru efectuarea calculelor matematice de bază.

Operator Semnificație Exemplu
+Adunare5+3 → 8
-Scădere5-3 → 2
*Înmulțire5*3 → 15
/Împărțire (Câtul)7/2 → 3 (între întregi)
%Restul împărțirii (modulo)7%2 → 1
Capcană frecventă la BAC: Operatorul / aplicat pe două numere întregi va trunchia rezultatul (elimină zecimalele): 7/2 → 3. Pentru un rezultat real, trebuie făcută o conversie explicită (cast) sau cel puțin un operand trebuie să fie real: (float)7/2 → 3.5.

Operatorul % (modulo) se aplică doar numerelor întregi:

if(n%2==0)
    cout<<"n este par";
else
    cout<<"n este impar";

Operatori relaționali și logici

Construiesc expresii cu valoare de adevăr (true / false, adică 1 / 0).

Operatori relaționali

  • == – egal (comparare)
  • != – diferit
  • <, > – strict mai mic/mare
  • <=, >= – mai mic/mare sau egal

Operatori logici

  • && – ȘI (AND): 1 dacă ambele sunt 1
  • || – SAU (OR): 1 dacă cel puțin una e 1
  • ! – NEGAȚIE (NOT): inversează valoarea
Evaluarea scurtcircuitată (Explicația IF-ului compus):
La BAC apar adesea condiții compuse (mai multe verificări în același if). C++ evaluează aceste condiții strict de la stânga la dreapta și se oprește imediat ce răspunsul final este sigur.

• La && (ȘI): dacă prima condiție e falsă, a doua nu se mai evaluează deloc (rezultatul total e clar fals).
• La || (SAU): dacă prima condiție e adevărată, a doua nu se mai evaluează deloc (rezultatul total e clar adevărat). 
int n=0;

// Explicație pas cu pas:
// 1. C++ evaluează prima parte: (n!=0). Deoarece n este 0, rezultatul este FALS.
// 2. Fiind legat de a doua condiție prin && (care cere ca ambele să fie adevărate), 
//    rezultatul final va fi oricum FALS. 
// 3. Astfel, C++ "scurtcircuitează" expresia și NU mai execută deloc a doua parte: (10/n==2).
// Avantaj: Am evitat cu succes o eroare fatală a programului (împărțirea la zero).

if(n!=0&&10/n==2){
    cout<<"Conditie indeplinita";
}

Operatori la nivel de bit (Bitwise)

Efectuează operații direct pe reprezentarea în baza 2 (binar) a numerelor întregi. Apar des la Subiectul I pentru optimizări matematice.

Operator Semnificație Exemplu / Efect practic
&ȘI pe biți (AND)x&1 verifică dacă x este impar.
|SAU pe biți (OR)x|1 transformă ultima cifră binară în 1.
^SAU Exclusiv (XOR)x^x este mereu 0.
~Negație pe biți (NOT)Inversează toți biții (0 devine 1, 1 devine 0).
<<Deplasare stânga (Shift left)x<<k este echivalent cu x*2k
>>Deplasare dreapta (Shift right)x>>k este echivalent cu x/2k

Ordinea (prioritatea) operatorilor

Tabelul complet al priorităților pentru programa de Bacalaureat, de la cea mai mare prioritate (1) la cea mai mică:

Nivel Operatori Tip
1 () [] Paranteze, indexare tablou
2 ++ -- ! ~ Unari (inclusiv negație, bitwise NOT)
3 * / % Multiplicativi
4 + - Aditivi
5 << >> Deplasare pe biți (Shift)
6 < <= > >= Relaționali de ordine
7 == != Relaționali de egalitate
8 & ^ | Bitwise AND, XOR, OR (în această ordine)
9 && ȘI logic
10 || SAU logic
11 ?: Operatorul ternar (condițional)
12 = += -= ... Atribuire (cea mai mică prioritate) 
int rezultat=2+3*4;    // 14 (inmultirea are prioritate)
int rezultat2=(2+3)*4; // 20 (parantezele schimba ordinea)

// Deoarece + are prioritate față de <<, expresia de mai jos 
// calculează 1<<(2+3), adică 1<<5 = 32
int shift=1<<2+3;

Operatorul ternar ?:

Singurul operator din C++ cu trei operanzi. Varianta compactă a structurii if-else.

Sintaxă:
condiție?valoare_adevarat:valoare_fals 
int a=7,b=12;
int maxim=(a>b)?a:b; // maxim va primi 12
