Operatori în C++

Tipurile de operatori, evaluarea expresiilor și capcanele frecvente din programa de BAC

Ce este un operator?

Un operator este un simbol care indică o operație ce trebuie efectuată asupra unuia sau mai multor operanzi. În funcție de numărul operanzilor, operatorii pot fi unari (un operand), binari (doi operanzi) sau ternari (trei operanzi).

Operatori aritmetici

Se folosesc pentru efectuarea calculelor matematice de bază.

Operator Semnificație Exemplu
+Adunare5+3 → 8
-Scădere5-3 → 2
*Înmulțire5*3 → 15
/Împărțire (Câtul)7/2 → 3 (între întregi)
%Restul împărțirii (modulo)7%2 → 1
Capcană frecventă la BAC: Operatorul / aplicat pe două numere întregi va trunchia rezultatul (elimină zecimalele): 7/2 → 3. Pentru un rezultat real, trebuie făcută o conversie explicită sau cel puțin un operand trebuie să fie real: (float)7/2 → 3.5.

Operatorul % (modulo) se aplică doar numerelor întregi:

if(n%2==0)
    cout<<"n este par";
else
    cout<<"n este impar";

Operatori de atribuire

Atribuirea combinată este o prescurtare frecvent utilizată în rezolvări.

Operator Echivalent cu Exemplu (pt. x=10)
=Atribuire simplăx=5; → x devine 5
+=x=x+valx+=3; → x devine 13
-=x=x-valx-=3; → x devine 7
*=x=x*valx*=2; → x devine 20
/=x=x/valx/=2; → x devine 5
%=x=x%valx%=3; → x devine 1

Operatori de incrementare / decrementare

Modifică valoarea unei variabile cu 1. Poziția lor stabilește momentul aplicării modificării.

Preincrementare: ++x

Valoarea lui x este mărită înainte de a fi folosită în expresie.

Postincrementare: x++

Valoarea lui x este folosită întâi, apoi este mărită.

int x=5;
cout<<++x; // afișează 6 (x devine 6, apoi se afișează)

int y=5;
cout<<y++; // afișează 5 (se afișează 5, apoi y devine 6)

Operatori relaționali și logici

Construiesc expresii cu valoare de adevăr (true / false, adică 1 / 0).

Operatori relaționali

  • == – egal (comparare)
  • != – diferit
  • <, > – strict mai mic/mare
  • <=, >= – mai mic/mare sau egal

Operatori logici

  • && – ȘI (AND): 1 dacă ambele sunt 1
  • || – SAU (OR): 1 dacă cel puțin una e 1
  • ! – NEGAȚIE (NOT): inversează valoarea

Operatori la nivel de bit (Bitwise)

Efectuează operații direct pe reprezentarea în baza 2 (binar) a numerelor întregi. Apar des la Subiectul I pentru optimizări matematice.

Operator Semnificație Exemplu / Efect practic
&ȘI pe biți (AND)x&1 verifică dacă x este impar.
|SAU pe biți (OR)x|1 transformă ultima cifră binară în 1.
^SAU Exclusiv (XOR)x^x este mereu 0.
~Negație pe biți (NOT)Inversează toți biții (0 devine 1, 1 devine 0).
<<Deplasare stânga (Shift left)x<<k este echivalent cu x*2k
>>Deplasare dreapta (Shift right)x>>k este echivalent cu x/2k

Ordinea (prioritatea) operatorilor și Evaluarea Expresiilor

Tabelul complet al priorităților pentru programa de Bacalaureat, de la cea mai mare prioritate (1) la cea mai mică:

Nivel Operatori Tip
1 () [] Paranteze, indexare tablou
2 ++ -- ! ~ Unari (inclusiv negație, bitwise NOT)
3 * / % Multiplicativi
4 + - Aditivi
5 << >> Deplasare pe biți (Shift)
6 < <= > >= Relaționali de ordine
7 == != Relaționali de egalitate
8 & ^ | Bitwise AND, XOR, OR (în această ordine)
9 && ȘI logic
10 || SAU logic
11 ?: Operatorul ternar (condițional)
12 = += -= ... Atribuire (cea mai mică prioritate)
Exemplu clar de evaluare a unei expresii unde ordinea contează (Fără scurtcircuitare):
Să analizăm pas cu pas expresia aritmetică de mai jos: 
int x=10+5*2-8/4;

// Pasul 1: Înmulțirea (*) și împărțirea (/) au prioritate mai mare (Nivelul 3):
//    - Se calculează 5*2=10
//    - Se calculează 8/4=2
// Expresia parțială devine: 10+10-2

// Pasul 2: Adunarea (+) și scăderea (-) au prioritate mai mică (Nivelul 4) 
// și se evaluează de la stânga la dreapta:
//    - Se calculează 10+10=20
//    - Se calculează 20-2=18

// REZULTAT FINAL: x va primi valoarea 18.

Operatorul ternar ?:

Singurul operator din C++ cu trei operanzi. Varianta compactă a structurii if-else.

Sintaxă:
condiție?valoare_adevarat:valoare_fals 
int a=7,b=12;
int maxim=(a>b)?a:b; // maxim va primi 12

Operatorul sizeof

Returnează numărul de octeți (bytes) ocupați în memorie de un tip de date sau de o variabilă. 

cout<<sizeof(int); // de regulă 4 octeți
int v[10];
cout<<sizeof(v);   // 40 (10 elemente x 4 octeți)
