Recursivitate

Arta de a rezolva o problemă apelând la... ea însăși

Ce este de fapt Recursivitatea?

În programare, recursivitatea este momentul în care un subprogram (o funcție) se apelează pe sine însuși din propriul său interior, până când o condiție de oprire este îndeplinită.

Orice funcție recursivă are obligatoriu două componente:
1. Cazul de bază (Condiția de oprire): Momentul în care funcția se oprește din a se mai autoapela și începe să returneze rezultate.
2. Autoapelul (Pasul recursiv): Partea în care funcția se cheamă pe ea însăși, dar cu date modificate, tinzând mereu spre cazul de bază.

Analogia cu Păpușile Matrioșka: Imaginează-ți că vrei să afli ce se ascunde în cea mai mică păpușă dintr-un set. Deschizi prima păpușă (funcția se apelează prima oară), găsești alta mai mică. O deschizi și pe aceea (autoapel cu date mai mici), și tot așa. Faci asta până ajungi la cea mai mică păpușă care nu se mai poate deschide (cazul de bază). Apoi, începi să le închizi la loc, una câte una, până ajungi înapoi la cea mare (descărcarea stivei).

Cum funcționează Stiva de Execuție (Stack-ul)?

Pentru a înțelege cum rulează o funcție recursivă, trebuie să înțelegem Stiva. Când o funcție se autoapelează, ea nu a terminat încă execuția. Ea se „pune pe pauză” și așteaptă ca funcția pe care a apelat-o să îi dea un răspuns. Toate aceste apeluri puse pe pauză se adună unele peste altele într-o memorie numită Stivă.

Varianta Iterativă (Cu "for")

int factorial_iterativ(int n)
{
    int p=1;
    for (int i=1;i<=n;i++)
    {
        p=p*i;
    }
    return p;
}

Varianta Recursivă

int factorial(int n)
{
    if (n==0) // Cazul de bază
        return 1; 
    else // Autoapelul
        return n*factorial(n-1);
}

Ce se întâmplă EXACT în calculator pentru factorial(3)?

1. factorial(3) intră pe stivă. Nu știe cât e factorial(2). Se pune pe pauză și îl cheamă.
2. factorial(2) intră pe stivă. Nu știe cât e factorial(1). Se pune pe pauză și îl cheamă.
3. factorial(1) intră pe stivă. Nu știe cât e factorial(0). Se pune pe pauză și îl cheamă.
4. factorial(0) a atins cazul de bază! Returnează 1 fără să se mai autoapeleze.

Acum stiva începe să se descarce (să dea răspunsurile înapoi):

5. factorial(1) primește 1-ul înapoi, face 1*1 și returnează 1.
6. factorial(2) primește 1-ul înapoi, face 2*1 și returnează 2.
7. factorial(3) primește 2-ul înapoi, face 3*2 și returnează răspunsul final: 6!

Urcarea vs. Coborârea pe stivă (Crucial la BAC - Subiectul II)

Adesea la BAC ți se dă un cod recursiv care afișează numere. Locul unde este pus cout schimbă total ordinea în care sunt afișate datele! Secretul este următorul:

Afișarea la URCARE

Dacă acțiunea (cout) se află ÎNAINTEA autoapelului, codul se execută imediat, în ordinea în care funcțiile intră pe stivă (din prima în ultima).

void afisare(int n)
{
    if (n>0)
    {
        cout<<n<<' '; // Se execută ACUM
        afisare(n-1);
    }
}
// Pentru afisare(3), afișează:
3 2 1

Afișarea la COBORÂRE

Dacă acțiunea (cout) se află DUPĂ autoapel, funcția este pusă pe pauză. Afișarea se va face doar la final, în ordine INVERSĂ, pe măsură ce stiva se golește.

void afisare(int n)
{
    if (n>0)
    {
        afisare(n-1);
        cout<<n<<' '; // Așteaptă întoarcerea!
    }
}
// Pentru afisare(3), afișează:
1 2 3

Problemă clasică: Suma cifrelor unui număr

O altă aplicație des întâlnită este prelucrarea cifrelor unui număr. Tăiem mereu ultima cifră (n/10) până când numărul devine 0.

int suma_cifre(int n)
{
    if (n==0)
        return 0; // Cazul de bază: numărul nu mai are cifre
    else
        return n%10+suma_cifre(n/10); // Ultima cifră + suma restului
}

Atenție la Capcanele mortale de la BAC!

  • Stack Overflow (Depășirea stivei): Dacă uiți să scrii cazul de bază sau dacă trimiți aceleași date la infinit (ex: autoapel cu `f(n)` în loc de `f(n-1)`), programul va apela funcția la nesfârșit. Calculatorul va rămâne fără memorie și programul va „crăpa” instantaneu.
  • Vectorii în funcții recursive: La Subiectul III, vei fi rugat des să parcurgi un vector recursiv. Reține mereu: vectorul (ex: v[]) se transmite doar prin referință, în timp ce indexul lui (ex: int n sau int i) dictează la ce element te uiți și cum faci avansul în recursivitate.
