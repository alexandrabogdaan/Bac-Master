Recursivitate

De la teorie la trasarea corectă a funcțiilor pentru Subiectul II și III de la BAC

Ce este Recursivitatea?

În programare, recursivitatea reprezintă proprietatea unui subprogram de a se apela pe sine însuși din propriul său corp, până la îndeplinirea unei condiții de oprire.

Structura obligatorie a oricărei funcții recursive:
1. Cazul de bază (Condiția de oprire): O condiție logică if care, odată îndeplinită, oprește autoapelul și returnează o valoare simplă, cunoscută.
2. Pasul recursiv (Autoapelul): Funcția se cheamă din nou, dar întotdeauna cu date modificate (ex: n-1, n/10), pentru a garanta că se îndreaptă spre cazul de bază. Fără această modificare, intrăm în ciclu infinit!

Analogia cu Păpușile Matrioșka: Imaginează-ți că vrei să afli ce se ascunde în cea mai mică păpușă dintr-un set. Deschizi prima păpușă (funcția se apelează prima oară), găsești alta mai mică. O deschizi și pe aceea (autoapel cu date mai mici), și tot așa. Faci asta până ajungi la cea mai mică păpușă care nu se mai poate deschide (cazul de bază). Apoi, începi să le închizi la loc, una câte una, până ajungi înapoi la cea mare (descărcarea stivei).

Recursivitate Liniară

Apare atunci când funcția se autoapelează o singură dată în corpul ei. Procesul arată ca o linie dreaptă: un apel duce la următorul, apoi la următorul. (Ex: factorialul, afișarea unui șir).

Recursivitate Multiplă

Apare când funcția se autoapelează de două sau mai multe ori la un singur pas. Creează un arbore de apeluri complex, nu o simplă linie. (Ex: șirul lui Fibonacci, generarea permutarilor).

Mecanismul stivei - Recursivitatea liniară

Când o funcție se autoapelează, execuția ei se suspendă (se pune pe pauză). Se alocă un spațiu nou în memorie, pe stivă, pentru noul apel. Funcția așteaptă ca apelul pe care tocmai l-a făcut să îi întoarcă un rezultat. Doar când se atinge cazul de bază, stiva începe să se golească în ordine inversă.

1. Forma Iterativă

int factorial_iterativ(int n)
{
    int p=1, i;
    for (i=1; i<=n; i++)
    {
        p=p*i;
    }
    return p;
}

2. Forma Recursivă

int factorial(int n)
{
    if (n==0)
        return 1; 
    else
        return n*factorial(n-1);
}

Cum se execută pas cu pas factorial(3)?

1. factorial(3) se oprește la return 3*factorial(2) și așteaptă.
2. factorial(2) se oprește la return 2*factorial(1) și așteaptă.
3. factorial(1) se oprește la return 1*factorial(0) și așteaptă.
4. factorial(0) intră pe cazul de bază! Returnează 1 direct.

Începe faza de întoarcere (Descărcarea stivei):

5. factorial(1) primește 1, face 1*1 și returnează 1.
6. factorial(2) primește 1, face 2*1 și returnează 2.
7. factorial(3) primește 2, face 3*2 și dă rezultatul final: 6.

Urcarea vs. Coborârea pe stivă (Secretul pentru BAC)

La exercițiile de la BAC, locul în care pui comanda cout dictează totul! Asta se întâmplă pentru că ai cod care se execută înainte ca funcția să se pună pe pauză, și cod care se execută doar după ce stiva se descarcă.

Acțiunea la URCARE

Dacă cout este scris ÎNAINTEA autoapelului, afișarea se face instantaneu. Se afișează de la primul apel spre ultimul.

void afisare(int n)
{
    if (n>0)
    {
        cout<<n<<' ';
        afisare(n-1);
    }
}
// Pentru afisare(3): 3 2 1

Acțiunea la COBORÂRE

Dacă cout este DUPĂ autoapel, funcția intră direct pe pauză. Afișarea are loc doar la golirea stivei, în ordine inversă!

void afisare(int n)
{
    if (n>0)
    {
        afisare(n-1);
        cout<<n<<' ';
    }
}
// Pentru afisare(3): 1 2 3

4 Algoritmi Recursivi Fundamentali la BAC

1. Suma cifrelor unui număr

Tăiem mereu ultima cifră (n/10) până când numărul ajunge la 0. Adunăm restul (n%10) la rezultat.

int suma_cifre(int n)
{
    if (n==0)
        return 0; 
    else
        return n%10+suma_cifre(n/10); 
}

2. CMMDC (Algoritmul lui Euclid)

Cea mai eficientă metodă recursivă se bazează pe împărțiri. Când restul devine 0, rezultatul este a.

int cmmdc(int a,int b)
{
    if (b==0)
        return a;
    else
        return cmmdc(b,a%b);
}

3. Șirul lui Fibonacci (Recursivitate Multiplă)

Orice termen este suma celor doi precedenți. Folosește două autoapeluri simultane pe același rând.

int fibonacci(int n)
{
    if (n==1 || n==2)
        return 1;
    else
        return fibonacci(n-1)+fibonacci(n-2);
}

4. Căutarea binară recursivă într-un vector

O tehnică avansată cerută la Subiectul III pentru a căuta un element într-un vector ordonat.

int cautare_binara(int v[],int st,int dr,int x)
{
    if (st>dr)
        return -1; // Nu s-a găsit
    int mij=(st+dr)/2;
    if (v[mij]==x)
        return mij;
    else if (v[mij]>x)
        return cautare_binara(v, st, mij-1, x);
    else
        return cautare_binara(v, mij+1, dr, x);
}

Cum să rezolvi perfect Subiectul II (Trasarea)

La Subiectul II vei primi o funcție întortocheată și vei fi întrebat, de exemplu, "Ce se afișează pentru f(123)?". Fă asta pe ciornă ca să nu greșești niciodată:

  • Nu încerca să deduci din minte! Desenează pe ciornă săgeți în jos pentru fiecare autoapel.
  • Notează valorile variabilelor locale lângă fiecare săgeată.
  • Dacă ai instrucțiuni după autoapel, amintește-ți că ele se rezolvă doar de jos în sus, mergând în sens invers pe săgețile pe care tocmai le-ai desenat pe foaie.
  • Eroarea fatală (Stack Overflow): Dacă observi că n nu își schimbă valoarea între apeluri (ex: apel cu f(n) în loc de f(n-1)), programul intră în ciclu infinit și dă eroare de memorie.
