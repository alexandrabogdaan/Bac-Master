Nota 10 la BAC

Tipul de date struct (Înregistrări)

Cum să grupăm variabile de tipuri diferite sub o singură „umbrelă”

Ce este tipul struct?

Până acum, am folosit vectori pentru a stoca mai multe elemente de același tip (ex: un vector doar cu numere întregi). Dar ce ne facem când dorim să descriem un obiect complex din lumea reală, care are caracteristici diferite?

Tipul struct ne permite să creăm propriul nostru tip de date, grupând la un loc variabile de tipuri diferite (numere, șiruri de caractere, etc.). Aceste variabile grupate se numesc câmpuri.

Analogia cu buletinul: Gândește-te la un elev. Un elev are un nume (șir de caractere), o vârstă (număr întreg) și o medie (număr real). Nu poți salva toate astea într-un singur vector obișnuit. Aici intervine struct, care creează un "șablon" numit Elev, conținând toate aceste 3 informații.

Cum declarăm o structură?

Declarația se face de obicei global (înainte de int main), pentru a putea fi recunoscută oriunde în program. Creăm mai întâi șablonul, apoi putem crea câte variabile dorim pe baza lui.

struct Elev {
    char nume[50];
    int varsta;
    float medie;
}; // <-- ATENȚIE: Aici este obligatoriu punctul și virgula!

Greșeală fatală la BAC

Uitarea punctului și virgulei ; la finalul acoladei care închide declarația unui `struct` este una dintre cele mai frecvente erori. Compilatorul va da o eroare ciudată pe rândurile următoare. Mereu pune ; după } la struct!

Accesarea și modificarea câmpurilor

Odată ce am creat șablonul Elev, putem declara variabile de acest tip în main. Pentru a accesa un câmp specific din interiorul structurii, folosim operatorul punct (.).

1. Declararea variabilei

Scriem tipul nou creat, urmat de numele variabilei (exact ca la un int a;).

Elev e1;

2. Accesarea cu punct

Formula este: NumeVariabila.NumeCâmp

e1.varsta=18;
#include <iostream>
#include <cstring>
using namespace std;

struct Elev {
    char nume[30];
    int varsta;
    float medie;
};

int main() {
    Elev e1; // Creăm o variabilă numită e1 de tipul Elev
    
    // Atribuim valori
    e1.varsta=18;
    e1.medie=9.50;
    strcpy(e1.nume, "Popescu Ion"); // Șirurile de caractere se copiază cu strcpy!
    
    // Afișăm datele
    cout<<"Elevul "<<e1.nume<<"are"<<e1.varsta<<" ani";
    
    return 0;
}

Ce operații putem face cu structurile întregi?

Nu putem aduna sau compara două structuri direct (nu putem scrie e1>e2 sau e1+e2). Aceste operații trebuie făcute câmp cu câmp (ex: e1.medie > e2.medie).

Operația permisă: Atribuirea (=)

Singura operație permisă direct între două variabile de același tip struct este atribuirea. Dacă scriem e2=e1;, compilatorul va copia automat absolut toate câmpurile din e1 în e2, scutindu-ne să o facem manual.

Elev e1, e2;
e1.varsta=18;
e1.medie=10;
strcpy(e1.nume, "Ana");

e2=e1; // Copiază instant numele, vârsta și media în e2!
cout<<e2.nume; // Va afișa Ana

Vectori de structuri (Tipic pentru BAC)

La examen, rareori vei avea un singur element. De cele mai multe ori ți se va cere să procesezi un șir de elemente (ex: 50 de candidați, 100 de fracții, etc.). Pentru asta, declarăm un vector în care fiecare element este de tipul struct creat de noi.

struct Fractie {
    int numarator;
    int numitor;
};

int main() {
    // Declarăm un vector care poate ține 100 de fracții
    Fractie v[100];
    int n=3, i; // Folosim doar 3
    
    // Citirea unui vector de structuri
    for(i=0; i<n; i++)
        cin>>v[i].numarator>>v[i].numitor;
  
    
    // Accesarea primei fracții:
    cout<<"Prima fracție este: "<<v[0].numarator<<"/"<<v[0].numitor;
    
    return 0;
}

Structuri Imbricate (Struct în Struct)

Un câmp al unei structuri poate să fie el însuși de un alt tip structurat. De exemplu, un elev are o dată a nașterii (zi, lună, an).

struct Data {
    int zi;
    int luna;
    int an;
};

struct Persoana {
    char nume[50];
    Data nastere; // Câmp de tipul Data (struct în struct)
};

int main() {
    Persoana p;
    strcpy(p.nume, "Andrei");
    
    // Folosim punctul de două ori pentru a "săpa" mai adânc
    p.nastere.zi=15;
    p.nastere.luna=8;
    p.nastere.an=2004;
    
    return 0;
}

Observă cum am folosit p.nastere.zi. Mai întâi accesăm variabila mare (p), apoi intrăm în componenta internă (nastere), și abia de acolo extragem câmpul final (zi).
