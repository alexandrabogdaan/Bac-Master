Șiruri de caractere

Aspecte teoretice și proceduri algoritmice fundamentale privind șirurile de caractere în C++.

Considerații generale privind șirurile de caractere

În limbajul C++, șirurile de caractere sunt implementate sub forma unor tablouri unidimensionale cu elemente de tip char. Din punct de vedere formal, un șir reprezintă o succesiune ordonată de caractere stocată într-o zonă de memorie contiguă, fiind delocată și delimitată în mod obligatoriu prin intermediul caracterului nul '\0'.

Caracterul nul '\0' posedă valoarea numerică ASCII 0 și îndeplinește rolul de marcator de sfârșit. Subprogramele specializate din biblioteca standard <cstring> se bazează pe prezența acestui delimitator pentru a stabili limitele de parcurgere a structurii.

Definirea și declararea structurilor de tip șir

Declararea unui șir de caractere se realizează prin specificarea tipului de date și a dimensiunii maxime: 

char sir[20];

În exemplul menționat, sunt alocate 20 de elemente consecutive, indexate în intervalul 0 – 19. Având în vedere necesitatea rezervării spațiului pentru terminatorul de șir '\0', numărul maxim de caractere efectiv utilizabile (utile) este de 19.

Modalitățile de inițializare la momentul declarării cuprind: 

char sir[20] = "Salut!";
// primele 6 poziții conțin caracterele 'S', 'a', 'l', 'u', 't', '!',
// iar următoarea poziție memorează valoarea '\0'

char t[] = "Salut!";
// dimensiunea tabloului este calculată în mod implicit de compilator
// (6 caractere + '\0' = 7 elemente alocate)

char v[6] = {'S', 'a', 'l', 'u', 't', '\0'};
// inițializare explicită element cu element

char a[] = {'S', 'a', 'l', 'u', 't', '\0'};
// determinarea automată a dimensiunii tabloului

Proceduri de citire și afișare

Afișarea la standardul de ieșire se execută cu ajutorul operatorului de inserție <<. 

cout<<sir;

Prelucrarea datelor de intrare fără inserarea de spații se realizează prin operatorul de extracție >>. 

cin>>sir;
Observație metodologică: Utilizarea operatorului de extracție permite exclusiv preluarea unor secvențe compacte (cuvinte), fluxul de citire sistându-se la primul caracter alb (spațiu) întâlnit.

Pentru achiziționarea integrală a unor fluxuri textuale care conțin spații se utilizează funcția membră specializată cin.getline(). 

cin.getline(sir, lungimea_sirului);
// Preia caractere din flux până la acționarea tastei Enter
// sau până la atingerea limitei maxime dimensionale stabilite.

Implementare și studiu de caz

Aplicația software de mai jos preia de la tastatură identificatorii nominali ai utilizatorului și ai unui terț, realizând ulterior afișarea structurată a acestora. 

#include <iostream>
using namespace std;

int main()
{
    char nume1[31], nume2[31];

    cout<<"Cum te cheamă? (nume și prenume): ";
    cin.getline(nume1, 31);

    cout<<"Cum îl cheamă pe prietenul tău? ";
    cin.getline(nume2, 31);

    cout<<"Te numești "<<nume1<<"\n";
    cout<<"Ești prieten cu "<<nume2<<"\n";

    return 0;
}

Accesarea elementelor și tehnici de parcurgere

Având o structură matricială unidimensională, manipularea elementelor individuale dintr-un șir se efectuează prin intermediul operatorului de indexare [].

Sistemul de indexare este orientat pe bază de zero, prima componentă corespunzând poziției 0, a doua poziției 1 ș.a.m.d. 

char sir[20] = "Salut!";

cout<<sir[0]; // afișează caracterul 'S'
cout<<sir[1]; // afișează caracterul 'a'

sir[1] = 'b';   // modifică starea șirului în "Sblut!"

cout<<sir;    // afișează Sblut!

Subprograme predefinite specifice bibliotecii <cstring>

Gestiunea avansată și operarea eficientă asupra șirurilor de caractere sunt asigurate prin intermediul funcțiilor standard incluse în antetul <cstring>.

Determinarea lungimii – strlen()

Funcția strlen(const char* str) returnează cardinalul mulțimii de caractere utile, excluzând în mod explicit terminatorul '\0'. 

cout<<strlen("Salut!"); // 6

char sir[10] = "Acasa";

cout<<strlen(sir);      // 5
cout<<strlen(sir + 2);  // 3

Copierea structurilor – strcpy()

Subprogramul strcpy(char* dest, const char* src) transferă fluxul de caractere conținut în parametrul src către locația dest, incluzând marcatorul de finalizare. 

char sir[21], t[21] = "Salut!";

strcpy(sir, "Acasa!");
cout<<sir; // Acasa!

strcpy(sir, t);
cout<<sir; // Salut!

strcpy(sir, t + 2);
cout<<sir; // lut!

strcpy(sir + 2, t);
cout<<sir; // luSalut!

Concatenarea șirurilor – strcat()

Procedura strcat(char* dest, const char* src) adaugă conținutul șirului sursă la capătul șirului destinație. Alocarea memoriei trebuie să fie suficient de mare pentru a preveni erorile de tip buffer overflow. 

char sir[21] = "Salut!";
char t[21] = "Acasa!";

strcat(sir, t);
cout<<sir; // Salut!Acasa!

strcat(sir, t + 2);
cout<<sir; // Salut!Acasa!asa!

Căutarea elementară – strchr()

Subprogramul strchr(char* str, char ch) identifică prima apariție a caracterului ch în interiorul șirului str. Returnează o referință de tip pointer către poziția detectată sau valoarea NULL în caz de eșec. 

char sir[21] = "Salut!";

char *p = strchr(sir, 'a');

cout<<p; // alut!

char ch = 'i';

if (strchr("aeiou", ch) != NULL)
{
    cout<<"DA";
}
else
{
    cout<<"NU";
}

// Valoare afișată: DA.

Căutarea subșirurilor – strstr()

Funcția strstr(char* str, char* str2) investighează prezența primei apariții a secvenței str2 în cadrul șirului principal str, returnând un pointer aferent sau valoarea NULL. 

char sir[21] = "Salut!";

char *p = strstr(sir, "alu");

cout<<p; // alut!
Notă teoretică: Pentru orice instanță a unui șir S, evaluarea expresiei strstr(S, "") furnizează permanent adresa de referință a primului element din șirul S.

Analiza lexicografică – strcmp()

Operatorul de comparare lexicografică

Funcția strcmp(char* s, char* t) realizează o evaluare a relației de ordine lexicografică între două șiruri de caractere conform codificării ASCII.

  • Returnează valoarea 0 în cazul egalității structurale.
  • Returnează o valoare strict negativă dacă primul parametru este inferior lexicografic.
  • Returnează o valoare strict pozitivă dacă primul parametru este superior lexicografic.
char s1[20] = "ana";
char s2[20] = "ana";
char s3[20] = "andrei";

cout<<strcmp(s1, s2); // 0
cout<<strcmp(s1, s3); // valoare negativă
cout<<strcmp(s3, s1); // valoare pozitivă

Partajarea structurală în tokeni – strtok()

Segmentarea lexicală a șirului

Funcția strtok(char* str, const char* sep) fragmentează fluxul inițial în subșiruri elementare (tokeni), utilizând drept criteriu de separare caracterele regăsite în mulțimea sep. La prima invocare se furnizează adresa șirului, urmând ca pentru parcurgerile ulterioare să se transmită valoarea NULL.

Aspect critic de proiectare: Acest subprogram alterează integritatea șirului inițial prin suprascrierea delimitatorilor detectați cu terminatorul nul '\0'. 
#include <cstring>
#include <iostream>
using namespace std;

int main()
{
    char s[100] = "ana are mere";

    char *p = strtok(s, " ");

    while (p != NULL)
    {
        cout<<p<<endl;
        p = strtok(NULL, " ");
    }

    return 0;
}

Algoritmi de inserare și eliminare a caracterelor

Procedura de eliminare

Pentru suprimarea elementului situat pe o poziție de indice x, se aplică o translație spre stânga a tuturor componentelor subsecvente.

Procedura de inserare

Pentru introducerea unui nou caracter la indexul x, elementele de la această poziție înainte sunt deplasate spre dreapta, creând spațiul necesar inserării. 

char s[20]="informatica";
int x=3;

for (int i=x; i<strlen(s); i++)
    s[i]=s[i+1];

cout<<s;
char s[30]="infoatica";
int x=4;

for (int i=strlen(s); i>=x; i--)
    s[i+1]=s[i];

s[x]='r';
cout<<s;
