Esențialul pentru Bacalaureat - Citire și scriere în fișiere text

Declararea și închiderea fișierelor

La BAC, poate fi necesar ca datele să fie citite din fișiere text și să se afișeze tot în fișiere. Numele fișierelor sunt date în enunț (de exemplu: date.in și date.out). 

#include <fstream>
using namespace std;
ifstream fin("date.in");   // declarare pentru citire
ofstream fout("date.out"); // declarare pentru scriere
int main()
{
    // ... prelucrări ...

    fin.close();
    fout.close();

    return 0;
}
