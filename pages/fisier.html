Lucrul cu Fișiere

Esențialul pentru Bacalaureat - Citire și scriere în fișiere text

De ce folosim fișiere?

Până acum, datele erau citite de la tastatură (cin) și afișate pe ecran (cout). Atunci când volumul de date este mare sau dorim ca rezultatele să rămână salvate permanent, folosim fișiere: citim datele de intrare dintr-un fișier și scriem rezultatele într-un alt fișier.

Observație: Pentru a lucra cu fișiere în C++, trebuie inclusă biblioteca <fstream>. Aceasta pune la dispoziție trei tipuri de obiecte: ifstream (citire), ofstream (scriere) și fstream (citire și scriere).

Tipurile de fluxuri (streams)

ifstream

Folosit pentru citirea datelor dintr-un fișier (input file stream).

ofstream

Folosit pentru scrierea datelor într-un fișier (output file stream).

fstream

Permite atât citirea, cât și scrierea în același fișier.

Declararea și închiderea fișierelor

#include <fstream>
using namespace std;
ifstream fin("date.in");   // declarare fișier in
ofstream fout("date.out"); // declarare fișier out
int main()
{
    // ... prelucrări ...

    fin.close();   // închidere fișier in
    fout.close(); // închidere fișier out

    return 0;
}

Citirea și scrierea datelor

Folosim operatorul >> pentru citire și << pentru scriere. Dacă trebuie să lucrăm cu caractere izolate, folosim tipul char. 

ifstream fin("date.in");
ofstream fout("date.out");

int x;
fin>>x; // citeste un numar

char c;
fin>>c; // citeste un caracter

fout<<x<<" "<<c<<"\n";
Citirea până la sfârșitul fișierului: Când nu se cunoaște numărul de elemente, citirea se face în buclă while: 
ifstream fin("date.in");
int x, s=0;
while (fin>>x)
{
    s+=x;
}

Exemplu

Program simplu care citește un șir de numere din date.in și scrie suma lor în date.out: 

#include <fstream>
using namespace std;
ifstream fin("date.in");
ofstream fout("date.out");
int main()
{
    int x, s=0;
    while (fin>>x)
    {
        s+=x;
    }

    fout<<s<<"\n";

    fin.close();
    fout.close();

    return 0;
}
