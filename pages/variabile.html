Variabile în C++

Identificatori, tipuri de date fundamentale, declarare, inițializare și sfera de cuprindere

Ce este o variabilă?

O variabilă este o zonă din memoria RAM rezervată pentru a păstra o valoare ce se poate modifica pe parcursul execuției programului. Fiecare variabilă are un nume (identificator), un tip de date, o adresă de memorie și o valoare.

Tipuri de date fundamentale pentru BAC

În programa de BAC pentru C++ se folosesc următoarele tipuri simple de date:

Tip Dimensiune Valori permise / Descriere Exemplu
int 4 octeți Numere întregi de la -2147483648 până la 2147483647 int x=10;
long long 8 octeți Numere întregi mari (până la aproximativ 9*10^18) long long n=123456789012;
float 4 octeți Numere reale (cu zecimale, precizie simplă) float medii=8.50;
double 8 octeți Numere reale (cu zecimale, precizie dublă) double pi=3.14159265;
char 1 octet Un singur caracter ASCII (între ghilimele simple) char c='A';
bool 1 octet Valori logice: true (1) sau false (0) bool ok=true;

Declarare și inițializare

Declararea unei variabile informează compilatorul cu privire la numele și tipul acesteia. Inițializarea constă în atribuirea unei valori inițiale.

int a; // declarare
a=5; // atribuire

int b=10; // declarare si initializare
int x=1,y=2,z=3; // declarare multipla
Constante cu const: Dacă adăugăm cuvântul cheie const înaintea tipului, valoarea variabilei nu mai poate fi modificată ulterior. 
const double PI=3.14159;
// PI=3.14; -> Eroare de compilare!

Variabile globale vs. variabile locale

Sfera de cuprindere (scope) reprezintă regiunea din cod în care o variabilă este accesibilă.

Variabile globale

Sunt declarate în afara oricărei funcții. Sunt accesibile în tot fișierul și sunt inițializate automat cu 0.

Variabile locale

Sunt declarate în interiorul unei funcții/bloc. Sunt accesibile doar în acel bloc și conțin valori reziduale (imprevizibile) dacă nu sunt inițializate! 

#include <iostream>
using namespace std;

int g; // variabila globala, g este 0 automat

int main(){
    int l; // variabila locala, valoare imprevizibila!
    int a=5; // variabila locala initializata
    cout<<g; // afiseaza 0
    return 0;
}
Capcană frecventă la BAC: Folosirea unei variabile locale neinițializate într-un calcul (de exemplu: int s; for(i=1;i<=n;i++) s+=i;) duce la un rezultat greșit deoarece s pleacă de la o valoare aleatorie din memorie, nu de la 0!
