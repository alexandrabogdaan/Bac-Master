Variabile și tipuri de date

Noțiuni fundamentale despre memorie, identificatori, constante și reprezentarea clară a datelor în C++

Definiția variabilei

În informatică, gestionarea corectă a datelor pornește de la înțelegerea conceptului de stocare temporară în memoria RAM a calculatorului.

Concept fundamental: O variabilă este o zonă precisă de memorie identificată printr-un nume (identificator), în care se stochează o valoare de un anumit tip. Această valoare poate fi modificată oricând pe parcursul execuției programului.

Atenție: În timp ce numele variabilei rămâne întotdeauna neschimbat, conținutul acesteia se poate modifica de oricâte ori este necesar prin operații de atribuire.

Identificatori (Numele variabilelor)

Un identificator este o secvență de caractere creată de programator pentru a denumi o variabilă, o constantă sau o funcție.

Reguli stricte de validitate în C++

  • Poate conține exclusiv litere (a-z, A-Z), cifre (0-9) și caracterul underscore (_).
  • OBLIGATORIU: Trebuie să înceapă cu o literă sau cu underscore (niciodată cu o cifră).
  • Limbajul C++ face diferență între literele mari și cele mici (de exemplu, variabila suma este complet diferită de variabila Suma).

Exemple utile pentru BAC

✅ Identificatori corecți: n, nr_elemente, _max, suma2

❌ Identificatori greșiți: 2suma (începe cu o cifră), nr-elemente (conține minus, care este operator matematic), int (este un cuvânt rezervat al limbajului).

Memoria și reprezentarea în biți

Calculatorul stochează absolut toate datele sub formă de biți, adică stări binare reprezentate strict prin valorile 0 și 1.

Bitul

Reprezintă cea mai mică unitate de informație dintr-un sistem de calcul, având exclusiv starea 0 sau starea 1.

Octetul (Byte-ul)

Reprezintă unitatea principală de memorie. Un grup format din exact 8 biți formează 1 Byte.

Grila de transformare a unităților de memorie:
  • 1 Byte = 8 biți
  • 1 KB (Kilobyte) = 1024 Bytes (2^10 Bytes)
  • 1 MB (Megabyte) = 1024 KB (2^20 Bytes)

Tipuri de date și alocarea în memorie

Următorul tabel prezintă structura completă a tipurilor primitive din C++ pe care trebuie să le cunoști perfect pentru examenul de Bacalaureat:

Tip de dată Dimensiune în memorie Tipul de valori și Intervalul permis
int 4 bytes (32 de biți) Numere întregi (cu semn): cuprinse aproximativ între -2 * 10^9 și 2 * 10^9
long long 8 bytes (64 de biți) Numere întregi foarte mari: de la -9 * 10^18 la 9 * 10^18 (Esențial pentru calculele mari de la Subiectul III)
unsigned int 4 bytes (32 de biți) Strict numere întregi pozitive: de la 0 la 4.29 * 10^9
float 4 bytes (32 de biți) Numere reale (cu virgulă, precizie simplă de aproximativ 7 zecimale)
double 8 bytes (64 de biți) Numere reale (cu virgulă, precizie dublă de aproximativ 15 zecimale)
char 1 byte (8 biți) Un singur caracter, reprezentat prin codul său ASCII (valori cuprinse între 0 și 255)
bool 1 byte Valori logice de adevăr (poate reține doar true sau false)

Analiza detaliată a tipurilor de date

Pentru a evita greșelile de punctaj la BAC, trebuie să înțelegi perfect cum se comportă fiecare tip de dată în situații limită:

Tipul int și depășirea limitei (Overflow)

Pentru tipurile numerice cu semn, primul bit din memorie este păstrat exclusiv pentru a indica semnul (0 înseamnă pozitiv, 1 înseamnă negativ). Dacă în urma unui calcul valoarea depășește limita maximă permisă (aproximativ 2.14 * 10^9), apare un fenomen critic numit overflow, iar numărul devine brusc negativ!

Regulă de aur la BAC: Dacă în cerința problemei se menționează că numerele pot avea până la 18 cifre sau dacă se cere produsul a mai multe numere mari, folosește întotdeauna tipul long long.

Tipurile reale (float și double)

Numerele reale sunt memorate în formatul standard cu virgulă mobilă, o reprezentare adaptată pentru a acoperi un interval vast de valori.

Atenție majoră: Aceste tipuri nu stochează întotdeauna valoarea matematică absolut exactă, ci o aproximație foarte apropiată de aceasta. Pentru o precizie maximă a calculelor la examen, se recomandă utilizarea tipului double.

Tipul char și Codul ASCII

Când declarăm o variabilă de tip char, calculatorul nu stochează litera în sine, ci un număr întreg cuprins între 0 și 255. Acest număr reprezintă codul ASCII asociat caracterului. Iată intervalele pe care trebuie să le știi pe de rost:

Cifrele '0'='9': coduri 48-57  |  Litere mari 'A'-'Z': coduri 65-90  |  Litere mici 'a'-'z': coduri 97-122

Tipul bool (Valori logice)

Acest tip de dată este esențial pentru condiții și acceptă doar două stări de bază:

  • Valoarea Adevărat: true (reprezentată în memoria calculatorului prin 1 sau prin orice altă valoare diferită de zero).
  • Valoarea Fals: false (reprezentată în memorie strict prin 0).

Declarare, Constante și Conversii de Tip (Casting)

1. Declararea și inițializarea variabilelor

O variabilă se creează specificând tipul de dată, urmat de identificator și opțional, atribuindu-i o valoare de pornire.

int a=10; // Aloca 4 bytes (pentru un numar intreg)
long long p=1000000; // Aloca 8 bytes (pentru un numar foarte mare)
double x=3.14; // Aloca 8 bytes (pentru un numar real)
char c='A'; // Aloca 1 byte (pentru a memora codul ASCII 65)
bool ok=true; // Aloca 1 byte (pentru o valoare de adevar)

2. Definirea Constantelor cu const

Constantele sunt spații de memorie protejate, a căror valoare nu mai poate fi modificată sub nicio formă pe parcursul programului. Dacă încerci să schimbi o constantă, programul va genera o eroare la compilare.

const double PI=3.14159;
const int MAX_VAL=100;

3. Conversia de tip (Typecasting) - Capcană frecventă!

În C++, atunci când împărțim două numere întregi, compilatorul returnează exclusiv un rezultat întreg (partea zecimală se pierde instantaneu, fără a face rotunjire). Pentru a forța programul să obțină un rezultat matematic cu virgulă, aplicăm conversia explicită (casting), adăugând tipul dorit între paranteze:

int a=5,b=2;

double r1=a/b; // r1 devine 2.0 (impartirea se face ca intre numere intregi, pierzand zecimalele)
double r2=(double)a/b; // r2 devine 2.5 (variabila 'a' este transformata temporar in real)
Concluzie pentru succesul la examen:
Cunoașterea perfectă a limitelor de memorie, alegerea tipului corect de dată (precum decizia de a folosi int versus long long), respectarea regulilor pentru identificatori și atenția la împărțirea numerelor întregi prin utilizarea conversiei explicite fac diferența clară între un algoritm parțial punctat și o rezolvare de nota 10.
