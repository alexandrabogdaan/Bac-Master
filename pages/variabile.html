Variabile și tipuri de date

Noțiuni fundamentale despre memorie, identificatori, constante și reprezentarea datelor în C++

Definiția variabilei

În informatică, gestionarea corectă a datelor pornește de la înțelegerea conceptului de stocare temporară în memoria RAM.

Concept fundamental: O variabilă este o zonă de memorie identificată printr-un nume (identificator), în care se stochează o valoare de un anumit tip, ce poate fi modificată pe parcursul execuției programului.

În timp ce numele variabilei (identificatorul) rămâne constant, conținutul acesteia se poate schimba de oricâte ori este necesar prin atribuiri.

Identificatori (Nume de variabile)

Un identificator este o secvență de caractere care denumește o variabilă, o constantă sau o funcție.

Reguli de validitate (C++)

  • Poate conține litere (a-z, A-Z), cifre (0-9) și caracterul underscore (_).
  • OBLIGATORIU: Trebuie să înceapă cu o literă sau cu _ (NICIODATĂ cu o cifră!).
  • Limbajul C++ este case-sensitive (face diferență între litere mari și mici: suma ≠ Suma).

Exemple utile pentru BAC

✅ Valide: n, nr_elemente, _max, suma2
❌ Invalide: 2suma (începe cu cifră), nr-elemente (conține minus), int (cuvânt rezervat).

Memoria și reprezentarea în biți

Calculatorul stochează toate datele sub formă de biți (stări binare de 0 și 1).

Bitul

Cea mai mică unitate de informație dintr-un sistem de calcul, având starea 0 sau 1.

Octetul (Byte)

Unitatea principală de adresare. Un grup de 8 biți formează 1 byte.

Grila de transformare a unităților:
  • 1 Byte = 8 biți
  • 1 KB (Kilobyte) = 1024 Bytes (2^10 Bytes)
  • 1 MB (Megabyte) = 1024 KB (2^20 Bytes)

Tipuri de date și alocarea în memorie

Structura completă a tipurilor primitive din C++ cerute la BAC:

Tip de dată Dimensiune memorie Tipul de valori & Interval
int 4 bytes (32 biți) Numere întregi conținând semn: de la -2 * 10^9 la 2 * 10^9
long long 8 bytes (64 biți) Numere întregi foarte mari: de la -9 * 10^18 la 9 * 10^18 (Util la Subiectul III)
unsigned int 4 bytes (32 biți) Doar numere întregi pozitive: de la 0 la 4.29 * 10^9
float 4 bytes (32 biți) Numere reale (precizie simplă, ~7 zecimale)
double 8 bytes (64 biți) Numere reale (precizie dublă, ~15 zecimale)
char 1 byte (8 biți) Un singur caracter codificat ASCII (valori de la 0 la 255)
bool 1 byte Valori logice (true / false)

Analiza detaliată a tipurilor de date

Detalii specifice despre modul de funcționare și limitările cerute la examen:

Tipul int și depășirile de tip (Overflow)

Primul bit este utilizat pentru semn (0 = pozitiv, 1 = negativ). Dacă o valoare depășește limita maximă (2.14 * 10^9), apare fenomenul de overflow (numărul devine negativ!).

Regulă BAC: Dacă în cerință se specifică numere cu până la 18 cifre sau produse mari, folosește întotdeauna long long!

Tipurile reale (float și double)

Numerele reale sunt salvate în formatul standard cu virgulă mobilă.

Atenție: Nu stochează întotdeauna valoarea matematică exactă, ci o aproximație. Pentru precizie maximă la BAC se recomandă double.

Tipul char și Codul ASCII

În memorie, tipul char este salvat ca un număr întreg reprezentând codul ASCII al caracterului. Codurile esențiale de memorat pentru BAC:

'0'=48 ... '9'=57  |  'A'=65 ... 'Z'=90  |  'a'=97 ... 'z'=122

Tipul bool (Valori logice)

Acceptă doar două stări:

  • true (reprezentat intern prin 1 sau orice valoare nenulă)
  • false (reprezentat intern prin 0)

Declarare, Constante și Conversii de Tip (Casting)

1. Declararea și inițializarea variabilelor

int a=10; // Aloca 4 bytes (numar intreg)
long long p=1000000; // Aloca 8 bytes (numar foarte mare)
double x=3.14; // Aloca 8 bytes (numar real)
char c='A'; // Aloca 1 byte (cod ASCII 65)
bool ok=true; // Aloca 1 byte (valoare logica)

2. Definirea Constantelor (`const`)

Constantele sunt valori care nu pot fi modificate pe parcursul programului. Orice încercare de a le schimba valoarea va genera eroare de compilare.

const double PI=3.14159;
const int MAX_VAL=100;

3. Conversia de tip (Typecasting) - Capcană de BAC!

Atunci când împărțim două numere întregi în C++, rezultatul este tot un număr întreg (se taie zecimalele). Pentru a obține un rezultat real, folosim **conversia explicită (casting)**:

int a=5,b=2;

double r1=a/b; // r1 va fi 2.0 (deoarece a/b se calculeaza mai intai ca intreg!)
double r2=(double)a/b; // r2 va fi 2.5 (a este convertit temporar la double)
Concluzie pentru BAC:
Cunoașterea limitelor de memorie, alegerea corectă a tipului de dată (`int` vs `long long`), atenția la denumirea identificatorilor și conversia explicită la împărțire reprezintă diferența dintre un algoritm parțial corect și unul de nota 10.
