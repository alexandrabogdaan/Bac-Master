Stiva și Coada

Structuri de date liniare fundamentale și implementarea lor clasică în C++

Ce sunt structurile liniare de date?

Stiva și Coada sunt structuri liniare de date prin intermediul cărora elementele sunt gestionate după reguli stricte de acces. În limbajul C++, pentru examenul de Bacalaureat, aceste structuri se implementează în mod clasic utilizând tablouri unidimensionale (vectori) și variabile de stare ce rețin pozițiile de lucru (cursori).

Stiva (Stack) – Principiul LIFO

Analogie: Gândește-te la o stivă de farfurii. O farfurie nouă se adaugă întotdeauna deasupra, iar când este necesară extragerea uneia, se preia tot farfuria din vârf.

Stiva funcționează pe baza principiului LIFO (Last In, First Out – ultimul element introdus este primul eliminat). Pentru implementarea clasică sunt necesare:

  • Un vector pentru stocarea elementelor: int st[100];
  • O variabilă ce indică poziția vârfului stivei: int varf=0;

Implementarea operațiilor fundamentale

int st[100];
int varf=0; // Valoarea 0 indică o stivă vidă

// 1. Inserarea unui element (Push)
void adauga(int x) 
{
    varf++;
    st[varf]=x;
}

// 2. Eliminarea elementului din vârf (Pop)
void elimina() 
{
    if(varf>0)
        varf--;
}

// 3. Accesarea elementului din vârf (Top)
int varf_stiva() 
{
    return st[varf];
}

// 4. Verificarea stării de stivă vidă (Empty)
bool este_vida() 
{
    return varf==0;
}

Coada (Queue) – Principiul FIFO

Analogie: Gândește-te la o coadă la o casierie. Prima persoană sosită este prima servită, iar persoanele noi se alătură la sfârșitul rândului.

Coada funcționează pe baza principiului FIFO (First In, First Out – primul element introdus este primul eliminat). Se gestionează prin intermediul a două capete:

  • Un vector pentru stocarea datelor: int c[100];
  • Indexul primului element (capul cozii): int prim=1;
  • Indexul ultimului element (sfârșitul cozii): int ultim=0;

Notă de configurare: Starea de coadă vidă este reprezentată prin condiția prim>ultim. Inițializarea prim=1 și ultim=0 respectă exact această condiție.

int c[100];
int prim=1;
int ultim=0;

// 1. Inserarea unui element la sfârșitul cozii (Enqueue)
void adauga(int x) 
{
    ultim++;
    c[ultim]=x;
}

// 2. Eliminarea primului element din coadă (Dequeue)
void elimina() 
{
    if(prim<=ultim)
        prim++;
}

// 3. Accesarea primului element (Front)
int primul_element() 
{
    return c[prim];
}

// 4. Verificarea stării de coadă vidă (Empty)
bool este_vida() 
{
    return prim>ultim;
}

Rezumat comparativ: Stivă vs. Coadă

Criteriu Stivă (Stack) Coadă (Queue)
Principiul de funcționare LIFO (Last In, First Out) FIFO (First In, First Out)
Capete de lucru Un singur capăt (vârful stivei), utilizat atât pentru adăugare, cât și pentru eliminare. Două capete: un capăt pentru adăugare (sfârșit) și un capăt pentru eliminare (început).
Condiție de structură vidă varf==0 prim>ultim
Aplicație tipică la BAC Evaluarea expresiilor, parantezarea corectă, recursivitatea. Algoritmul lui Lee, parcurgerea în lățime a grafurilor (BFS).

Aplicarea cozii în Algoritmul lui Lee și BFS (Subiecte BAC)

Mecanismul de lucru cu variabilele p (prim) și u (ultim) nu este specific doar Algoritmului lui Lee. Aceasta este modalitatea clasică de parcurgere în lățime (BFS – Breadth-First Search) și se aplică în egală măsură la parcurgerea grafurilor, la algoritmul Fill sau la orice simulare de tip "primul venit, primul servit".

Corespondența dintre operațiile cozii și codul C++ este următoarea:

  • p=u=1; – Inițializarea cozii cu elementul de start (starea inițială).
  • while(p<=u) – Structura repetitivă rulează cât timp coada nu este vidă (condiția prim<=ultim).
  • poz=c[p++]; – Preluarea elementului din capul cozii și avansarea indexului p (extragere).
  • c[++u]=v; – Adăugarea unui element nou valid la finalul cozii și incrementarea indexului u (inserare).

Secvența C++ standard pentru Algoritmul lui Lee (Model BAC)

// Structură pentru reținerea coordonatelor în matrice
struct Pozitie 
{
    int lin, col;
};

Pozitie c[200*200]; // Coada propriu-zisă
Pozitie poz, v;
int p, u;

// Vectori de deplasare (Nord, Est, Sud, Vest)
int dl[]={-1, 0, 1, 0};
int dc[]={0, 1, 0, -1};

// Algoritmul lui Lee
p=u=1;
c[1].lin=xi;
c[1].col=yi;
b[xi][yi]=1; // Marcăm poziția de start cu distanța 1

while(p<=u) {
    poz=c[p++]; // Extragere din coadă
    int k;
    for(k=0; k<4; k++) 
    {
        v.lin=poz.lin+dl[k];
        v.col=poz.col+dc[k];
        
        // Dacă vecinul este liber și nevizitat
        if(a[v.lin][v.col]==0 && b[v.lin][v.col]==0) 
        {
            b[v.lin][v.col]=b[poz.lin][poz.col]+1;
            c[++u]=v; // Inserare în coadă
        }
    }
}

Concluzie pentru examen

Reținere importantă:
La examenul de Bacalaureat se recomandă utilizarea tabelelor și variabilelor simple de indexare (implementarea clasică). Identifică regula din enunț: dacă ordinea de procesare este inversă ordinii de introducere, problema necesită o Stivă (LIFO); dacă ordinea se păstrează, problema necesită o Coadă (FIFO).
